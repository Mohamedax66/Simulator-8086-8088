# 8086 Microprocessor Simulator & Visual Architecture
### محاكي معالج 8086 التفاعلي ونظام المعمارية المرئية ومصحح الأخطاء الذكي

---

## 🌟 نظرة عامة (Overview)
تطبيق ويب احترافي ومتكامل لمحاكاة معالج **Intel 8086** وكتابة وتجميع وتتبع أكواد الـ Assembly خطوة بخطوة في المتصفح مباشرة دون الحاجة لتثبيت أي برامج خارجية أو بيئات DOS القديمة.

يتميز التطبيق بتمثيل مرئي حي وديناميكي للمعمارية الداخلية للبروسيسور، وتتبع مسار النواقل وبنوك الذاكرة، مع **مصحح ذكي للأخطاء (Smart Error Corrector) ينبه تلقائياً براية حمراء 🚩 عند السطر الذي يحتوي على خطأ برمجي مع إمكانية تصحيحه بضغطة زر واحدة**.

---

## 🚀 المميزات الرئيسية (Key Features)

### 1. مصحح الأخطاء الذكي وراية التنبيه (Smart Corrector & Red Flag 🚩)
* **تنبيه مرئي مباشر:** يظهر رمز الراية الحمراء المتوهجة **🚩** على رقم السطر فور وجود خطأ نحوي أو منطقي في الكود.
* **فحص دقيق لقواعد 8086 Assembly:**
  * اكتشاف الأخطاء الإملائية في أسماء التعليمات (مثل كتابة `MOVE` أو `ADDS`) واقتراح التعليمة الصحيحة (`MOV`, `ADD`).
  * فحص عدم توافق أحجام المعاملات (Operand Size Mismatch)، مثل محاولة نقل مسجل 8-بت إلى 16-بت (`MOV AX, BL`).
  * منع العمليات غير المسموح بها في معمارية 8086، مثل النقل المباشر من ذاكرة إلى ذاكرة (`MOV [BX], [SI]`) أو استخدام الثوابت كوجهة (`MOV 50, AX`).
  * فحص صحة مسجلات العنونة داخل الأقواس `[...]` والتنبيه إذا استُخدم مسجل غير مسموح به (مثل `[AX]`).
  * فحص تجاوز سعة البايت (Value Overflow) في المسجلات 8-بت.
  * فحص القفز إلى أسماء ملصقات (Labels) غير معرّفة.
* **زر التصحيح التلقائي (One-Click Auto-Fix):** يعرض المصحح بطاقة توضيحية لسبب الخطأ مع زر **"Apply Fix"** لاستبدال السطر بالصيغة الصحيحة فوراً!

### 2. التمثيل المرئي المباشر لوحدتي المعالج (BIU & EU Architecture)
* **وحدة الربط مع النواقل (Bus Interface Unit - BIU):**
  * مسجلات المقاطع الأربعة (`CS`, `DS`, `SS`, `ES`) ومسجل مؤشر التعليمات (`IP`).
  * **مولد العناوين المخصص (20-bit Dedicated Adder):** يعرض المعادلة الحية لكل وصول:
    $$\text{Physical Address} = (\text{Segment} \times 10\text{H}) + \text{Offset}$$
  * **طابور الجلب المسبق (FIFO Prefetch Queue):** 6 خانات بايت لمعالج 8086 (و 4 خانات لـ 8088) توضح كيف يتم جلب التعليمات مسبقاً بالتوازي مع التنفيذ (Pipelining).
* **وحدة التنفيذ (Execution Unit - EU):**
  * مفكك التعليمات والتحكم (Instruction Decoder).
  * وحدة الحساب والمنطق 16-بت (16-bit ALU).
  * المسجلات العامة (`AX`, `BX`, `CX`, `DX`) ومسجلات المؤشرات والفهارس (`SP`, `BP`, `SI`, `DI`).
  * مسجل الأعلام الكامل وتحديث أعلام الحالة الستة (`CF`, `PF`, `AF`, `ZF`, `SF`, `OF`) مع شرح تفصيلي لسبب تغير كل علم.

### 3. محاكاة بنوك الذاكرة الفيزيائية الحقيقية (Two Physical Memory Banks)
* تمثيل بنكي الذاكرة الفيزيائية (512 KB لكل بنك):
  * **Even Bank (Low Bank):** متصل بـ $D_0 - D_7$ ويُفعَّل بإشارة $A_0 = 0$.
  * **Odd Bank (High Bank):** متصل بـ $D_8 - D_{15}$ ويُفعَّل بإشارة $\overline{\text{BHE}} = 0$.
* تفعيل البنكين معاً في دورة ساعة واحدة (**1 Clock Cycle**) عند قراءة كلمة محاذاة في عنوان زوجي، ودورتين للكلمات غير المحاذاة.
* **التبديل بين معالج 8086** (ناقل 16-بت، بنكين، طابور 6 بايت) و **معالج 8088** (ناقل 8-بت، بنك واحد، طابور 4 بايت).

### 4. الدعم الكامل لأنماط العنونة السبعة (The 7 Data Addressing Modes)
1. **Register Addressing:** `MOV AX, BX`
2. **Immediate Addressing:** `MOV CH, 3AH`
3. **Direct Data Addressing:** `MOV AL, [1234H]`
4. **Register Indirect Addressing:** `MOV AX, [BX]`
5. **Base-Plus-Index Addressing:** `MOV DX, [BX+DI]`
6. **Register Relative Addressing:** `MOV AX, [BX+1000H]`
7. **Base Relative-Plus-Index Addressing:** `MOV AX, [BX+SI+100H]`

### 5. الأجهزة الطرفية والمنافذ (I/O Peripherals & Terminal)
* **Port 1 (Input Port):** إدخال قيم يدوية بالـ Hex وقراءتها بتعليمة `IN AL, 1`.
* **Port 2 (8 Virtual LEDs):** شريط 8 ليدات تفاعلية يضيء ويطفئ بتعليمة `OUT 2, AL`.
* **Port 3 (7-Segment Display):** شاشة سباعية تعرض الأرقام من `0` إلى `F` بتعليمة `OUT 3, AL`.
* **Port 8 & DOS INT 21h (Virtual Terminal):** تدعم طباعة وقراءة النصوص ومقاطعات نظام DOS (`AH=01h`, `AH=02h`, `AH=09h`, `AH=4Ch`).

### 6. ميزة التراجع الزمني (Time-Travel / Step Back)
* إمكانية الرجوع بالزمن خطوة للوراء بضغطة زر `Step Back` لاستعادة حالة المسجلات والذاكرة والأعلام السابقة.
* نقاط توقف تفاعلية (Breakpoints) بالنقر المباشر على أرقام الأسطر.

## 💻 طريقة التشغيل (How to Run)
المشروع مبني بـ HTML5 و CSS3 و Vanilla JavaScript الخالص بدون أي تبعيات (Zero External Dependencies):
1. افتح الملف `index.html` في أي متصفح حديث (Chrome أو Microsoft Edge أو Firefox).
2. أو شغل خادم محلي خفيف في مجلد المشروع:
   ```bash
   python -m http.server 8000
   ```
   ثم افتح `http://localhost:8000` في المتصفح.
