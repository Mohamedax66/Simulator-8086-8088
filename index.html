Intel 8086 Microprocessor Reference Guide

1. Physical Address Generation (Real Mode)

Registers are 16-bit, so they can only address up to 64 KB ($2^{16}$). To access 1 MB of memory ($2^{20}$), segmentation is used:

Physical Address = (Segment Register × 10H) + Offset

  • Starting Address of Segment: Segment × 10H (Ends with 0H).
  • Ending Address of Segment: (Segment × 10H) + FFFFH (Length = 64 KB).

2. Physical Memory Banks Organization

  • Even Bank (Low Bank, 512 KB): Connected to Data Bus D0-D7. Selected by A0 = 0. Contains even addresses (0, 2, 4...).
  • Odd Bank (High Bank, 512 KB): Connected to Data Bus D8-D15. Selected by BHE# = 0. Contains odd addresses (1, 3, 5...).
  • Word Transfer: Aligned 16-bit word starting at even address takes 1 clock cycle (Both banks activated). Misaligned word starting at odd address takes 2 clock cycles.

3. Default Segment & Offset Pairings

  • Code Segment (CS): Paired with IP (Instruction Pointer).
  • Data Segment (DS): Paired with BX, SI, DI, or direct displacement.
  • Stack Segment (SS): Paired with SP (Stack Pointer) or BP (Base Pointer).
  • Extra Segment (ES): Paired with DI (Destination Index in string instructions).

4. Status Flags (ALU Calculations)

  • CF (Carry Flag): Carry out of MSB or borrow.
  • ZF (Zero Flag): 1 if result is zero, 0 otherwise.
  • SF (Sign Flag): MSB of result (1 for negative, 0 for positive).
  • PF (Parity Flag): 1 if low byte has EVEN count of 1-bits, 0 for odd.
  • AF (Auxiliary Carry): Half-carry between bit 3 and bit 4 (nibbles).
  • OF (Overflow Flag): Signed arithmetic overflow (adding two positives gives negative, or two negatives gives positive).
